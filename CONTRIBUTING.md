## How to Contribute / 기여 방법

### Reporting Bugs / 버그 리포트
- Use the [Bug Report](../../issues/new?template=bug_report.md) template
- Include Unity version, SDK version, and OS
- Provide clear reproduction steps

---

- [Bug Report](../../issues/new?template=bug_report.md) 템플릿을 사용해주세요
- Unity 버전, SDK 버전, OS 정보를 포함해주세요
- 재현 단계를 명확하게 작성해주세요

---

### Suggesting Features / 기능 제안
- Use the [Feature Request](../../issues/new?template=feature_request.md) template
- Describe the use case and proposed solution

---

- [Feature Request](../../issues/new?template=feature_request.md) 템플릿을 사용해주세요
- 사용 사례와 제안하는 솔루션을 설명해주세요

## Code Contributions / 코드 기여

### English

1. **Fork** the repository
2. Create a **feature branch**: `git checkout -b feature/amazing-feature`
3. **Commit** your changes: `git commit -m 'Add amazing feature'`
4. **Push** to the branch: `git push origin feature/amazing-feature`
5. Open a **Pull Request**

### 한국어

1. 레포지토리를 **Fork** 합니다
2. **feature 브랜치** 생성: `git checkout -b feature/amazing-feature`
3. 변경사항 **커밋**: `git commit -m 'Add amazing feature'`
4. 브랜치에 **Push**: `git push origin feature/amazing-feature`
5. **Pull Request** 생성

## Code Style / 코드 스타일

| Rule | 규칙 |
|------|------|
| Follow C# naming conventions | C# 네이밍 규칙 준수 |
| Use `#region` for code organization | 코드 구성에 `#region` 사용 |
| Add XML documentation for public APIs | 공개 API에 XML 문서 추가 |
| Test in Unity 2022.3 LTS | Unity 2022.3 LTS에서 테스트 |
