# Contributing to VARCO Voice Unity SDK

Thanks for taking the time to contribute.

## Ways to Help

- Report bugs through GitHub Issues
- Request features through GitHub Issues
- Submit pull requests for focused fixes or improvements
- Improve documentation and examples

## Before You Open an Issue

Please include:

- Unity version
- SDK version or tag
- Operating system
- Clear reproduction steps
- Expected behavior
- Actual behavior
- Relevant logs or screenshots

## Pull Request Workflow

1. Fork the repository.
2. Create a topic branch from `main`.
3. Keep the change focused and easy to review.
4. Update docs or changelog when behavior changes.
5. Open a pull request with a concise summary and validation notes.

## Code Style

- Follow standard C# naming conventions.
- Keep public APIs documented when behavior is not obvious.
- Prefer small, reviewable changes over large refactors.
- Test in Unity 2022.3 LTS when possible.
