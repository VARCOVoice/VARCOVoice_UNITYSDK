# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-15

### Added
- Initial release
- VARCO Voice TTS API integration (Standard & Lite models)
- Voice Conversion (VC) support
- 1,293+ voice speakers support
- Audio DSP chain with effects:
  - Pitch Shifter
  - Reverb
  - 3D Spatial Audio
  - EQ
  - Low Pass Filter
  - Chorus
- Real-time lip sync analysis
- Korean phoneme to Viseme mapping
- Editor tools:
  - Voice Picker Window
  - TTS Preview Tool
  - Project Settings integration
- Sample scenes:
  - Basic TTS
  - Dialogue System
  - 3D Spatial Audio
  - Lip Sync
  - DSP Effects
