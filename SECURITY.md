## Reporting a Vulnerability / 취약점 신고

### English

If you discover a security vulnerability, please report it by:

1. **Email**: varcovoice.ncsoft@gmail.com
2. **Subject**: `[SECURITY] VARCO Voice Unity SDK`

**Please do NOT open a public GitHub issue for security vulnerabilities.**

#### What to include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

#### Response Timeline
- **Initial Response**: Within 48 hours
- **Status Update**: Within 7 days
- **Resolution**: Depends on severity

---

### 한국어

보안 취약점을 발견하셨다면 다음 방법으로 신고해주세요:

1. **이메일**: varcovoice.ncsoft@gmail.com
2. **제목**: `[SECURITY] VARCO Voice Unity SDK`

**보안 취약점은 공개 GitHub 이슈로 등록하지 마세요.**

#### 포함할 내용:
- 취약점 설명
- 재현 단계
- 잠재적 영향
- 수정 제안 (있는 경우)

#### 응답 일정
- **초기 응답**: 48시간 이내
